# 수호의 폰 · 팬메이드

《약한영웅》 안수호에서 영감을 받은 비공식 팬메이드 가상 스마트폰 웹사이트입니다.

## 실행 방법
- `index.html` 파일을 브라우저에서 열면 됩니다.
- GitHub Pages로 공개하려면 이 파일을 저장소의 루트에 올리고, 저장소 Settings → Pages에서 배포를 설정하세요.

## 포함 기능
- 스마트폰 홈 화면
- 가상 카카오톡 대화 및 메시지 입력
- 갤러리 플레이스홀더
- 메모 작성 및 브라우저 저장
- 음악 앱 재생 상태 UI
- 가상 통화 기록

모든 대화와 통화 기록은 창작된 예시이며, 실제 인물의 기기나 데이터와 관련이 없습니다.
